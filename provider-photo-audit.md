# Provider portrait edge audit

Audit scope: all 60 provider detail-page hero portraits.

No provider images were changed during this audit. Each page's current hero asset was reviewed against the UCS blue. "Priority" means the crop has an obvious geometric artifact or the original rectangular background is still visible. "Side crop" means an arm, shoulder, or torso reaches the source image boundary and should be extended before the background is removed.
