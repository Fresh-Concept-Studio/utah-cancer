# Utah Cancer Specialists CMS

This Sanity Studio manages public marketing content for utahcancer.com. Do not enter patient information, contact-form submissions, employment applications, medical records, or other private data here.

Publishing a document updates the public dataset and triggers a verified static-site rebuild. Existing site image paths remain valid; editors can upload replacement profile and location images from the Studio.

The Studio belongs to the Fresh Concept organization. Give the client Administrator access to this project so both parties retain access on Sanity's Free plan.
