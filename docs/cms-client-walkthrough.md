# Client CMS walkthrough

Start at [Website pages](https://utah-cancer-specialists.sanity.studio/structure/pages). The same editor is available inside the Sanity dashboard. Refresh once after the Studio update.

## A short Loom outline

1. **Find a page.** Show the searchable Website pages directory. Search for Home, a provider name, or a clinic. Main pages, Providers, and Locations in the left menu are shortcuts.
2. **Edit page text.** Open Home → Page content. Expand a section and change its text. The layout is preserved. Search within the page when looking for a particular phrase.
3. **Replace an image.** Open Images, choose an image, upload its replacement, and enter a short description. Existing images stay in place until replaced.
4. **Edit a provider.** Open a provider’s profile. Change a biography paragraph or headshot. Select practice locations using named checkboxes with addresses.
5. **Explain shared content.** Open Related content. A directory reuses provider and clinic records. Leadership groups and media appearances have shared settings so changes can be reused. Clinic contact cards can have distinct suite details; check the linked cards when contact information changes.
6. **Publish.** Changes save as a draft. Publish only when ready. Allow a few minutes for the website build to finish, then refresh the public page. Published website shows the live page, not an unpublished preview.
7. **Show help.** Start here contains the instructions. Contact Fresh Concept if an update does not appear after several minutes or if the change needs a new layout, navigation item, or form field.

## Other useful edits

- **Careers:** Job openings tab. Add, edit, reorder, or remove a listing, then publish the Careers page.
- **About:** Page content → The scope of our impact. Edit statistics and their labels.
- **Leadership:** Related content → Leadership directory, media & shared contact settings → Leadership directory. Choose linked profiles, edit roles, or change group order.
- **Videos:** Shared content & contact cards → Leadership directory & media → Media & videos.
- **Search results:** Search appearance on the relevant page.

## What to explain clearly

- The CMS edits content within the existing design. Layout and form changes go through Fresh Concept.
- Each related record has its own Publish button.
- Page addresses are locked after creation to protect existing links.
- Do not put patient information, employment applications, or private records in this CMS.
- A saved draft is not public. If publication fails validation, resolve the message or contact Fresh Concept.
