# Utah Cancer Specialists CMS

This Sanity Studio manages public marketing content for utahcancer.com. Do not enter patient information, contact-form submissions, employment applications, medical records, or other private data here.

Publishing a document updates the public dataset and triggers a verified static-site rebuild. Existing site image paths remain valid; editors can upload replacement profile and location images from the Studio.

Start in **Website pages** to find and edit a page. Main-page text and images are grouped into sections; **Related content** links to profiles and shared records. **Published website** shows the live site, not unpublished drafts.

The Studio belongs to the Fresh Concept organization. Each client editor should use their own login with the editing and publishing access available on the current plan. Keep administration separate when the plan supports it.

See [CMS documentation](../docs/sanity-cms.md) for deployment and content-safety rules, and [the client walkthrough](../docs/cms-client-walkthrough.md) for a short Loom outline.
